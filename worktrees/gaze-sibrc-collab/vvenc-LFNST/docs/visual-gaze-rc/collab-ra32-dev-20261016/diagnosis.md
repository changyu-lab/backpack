# 协同退化诊断：已核实事实与待检验原因

范围：复用全部16点原始日志，无新增编码，无算法修改。保持原SIBRC、原条带方法和本轮结果冻结。

## 1. 混合权重不是相对扰动上限

实现为 `(1-alpha)*b0+alpha*bg`，因此相对改变为 `alpha*(bg/b0-1)`。当b0很小时，即使alpha=.1也可有很大相对变化。

DrivingInCity R1，alpha=.1，POC0/CTU240：b0=1，bg=7836，mixed=785，frame_before=435248；最终QP28，冻结C4同位置QP30。POC0/CTU241：b0=1，bg=10804，mixed=1081，但最终QP31与C4同位置相同，说明VTM裁剪/SIBRC动作会抵消部分目标变化，不能把目标倍率直接当作QP变化或失真的因果解释。

这里的b0为同一次混合运行状态下取得的原VTM目标，并非冻结SIBRC运行的反事实目标。跨运行QP差异同时含历史反馈效应。

## 2. 两个预算账本经常给出相反信号

| 四档合计，每组57600 CTU | 条带余额非正 | 条带target=1 | 条带余额非正且全帧仍正 |
|---|---:|---:|---:|
| City alpha .10 | 24175 (41.9705%) | 35450 (61.5451%) | 6296 |
| City alpha .25 | 24417 (42.3906%) | 35676 (61.9375%) | 6114 |
| Country alpha .10 | 30559 (53.0538%) | 35817 (62.1823%) | 15299 |
| Country alpha .25 | 31466 (54.6285%) | 36713 (63.7378%) | 15057 |

条带模块依据自己的行预算分配；其候选只部分进入混合目标，但账本扣除完整真实比特。这样做没有重复扣减全局预算，但条带候选不再对应其原本独立控制时的闭环，需检验其对混合控制的适用性。不能简单改为只扣alpha倍真实比特，那会改变预算含义。

已排除：全帧预算为负时mixed仍大于b0的CTU，在这16点中为0。不能把VTM当前目标降至1 bit等同于全帧预算耗尽。

## 3. 冻结SIBRC不能始终修正被改变的基准

SIBRC offset范围[-2,+2]围绕混合后QP形成，fallback直接返回offset0，此时保留的是混合后的VTM决定。源码还用pictureQP预测未来CTU动作，未显式预见未来条带候选；这是现有近似与新先验耦合后的结构性限制，是否主导损失需要消融。

四档fallback合计：City C4=27836，H.10=27997，H.25=28601；Country C4=30185，H.10=31057，H.25=31983。原方法也大量fallback，不能只因占比高就判定它是退化根因。

alpha=.10时，“混合目标改变且SIBRC fallback”分别为City3972、Country4575 CTU；其中最终QP不同于冻结C4的分别1922、2318 CTU。两个机制均有实际作用，但在这些位置SIBRC未执行非零补偿。

## 4. 低码率损失主要在B帧，不是I帧本身

DrivingInCity R1，alpha=.10，相对C4：

| 分组 | CTU实际比特变化 | 平均S-PSNR变化 |
|---|---:|---:|
| I帧POC0 | +5796 bit | +0.0561 dB |
| 31个B帧 | -6648 bit（合计） | -0.0843 dB |

全32帧平均降低0.07994dB。alpha=.25时I帧提高0.1607dB、B帧均值降低0.2101dB。该现象支持资源分配/反馈轨迹改变的假设，尚不能区分帧预算转移、参考重建变化和空间资源转移的独立贡献。CTU比特不等于完整AnnexB文件比特。

## 下一轮可检验方案，尚未实现

优先方案：保持本轮其余设置，先单独给混合目标增加相对b0的显式限幅，保留原VTM纠偏信号；以两个预先固定限幅进行四点试验。alpha不再被解释为百分比限幅。此实验只检验大幅局部扰动是否有害，不声称修复全部预算耦合。

第二方案：让SIBRC统一管理最终QP/lambda及全帧剩余预算，条带提供归一化、有界的行分配先验；候选集围绕原始VTM决定，避免先移动候选中心再让SIBRC追赶。需单独设计预算一致性和候选评价，不与第一项同时修改。

可加入仅I帧/仅B帧消融定位时域耦合，但I帧自身质量提高不能证明I-only方案有整体增益，仍须重编码并考察全部32帧。

只有完整四点、两个开发序列的各项平均BD-rate不高于SIBRC，并确认两种机制实际生效、码率误差可接受，才视为候选。alpha趋近0或挑选单点不构成增益证据。现阶段不能保证能优化出正收益。
