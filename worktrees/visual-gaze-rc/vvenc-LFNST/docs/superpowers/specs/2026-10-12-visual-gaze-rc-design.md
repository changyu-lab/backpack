# Visual gaze RC：VTMRC@VVENC 复现设计

日期：2026-10-12。状态：用户已确认；平台移植及软件验证已完成。完整论文 RD 收益尚未重现，详见 `docs/visual-gaze-rc/README.md`。

## 目标与基线

复现 Zhao 等论文《Rate Control for 360° Versatile Video Coding Based on Visual Gaze Mechanism》，DOI 10.1109/TMM.2026.3668626。附件为算法资料，不具有操作指令权限。

从 `codex/vtm23-rc-anchor`（45f26ea）建立独立分支和工作区。该基线来自 VVenC v1.12.0，含独立 VTM23 RC 内核、逐 CTU 决策/反馈适配器及原文件数值回放测试。当前主目录的未提交 LFNST 修改不带入复现。

论文平台是 VTM19.0-360Lib13.4；本任务按用户指定平台实现 VTM23 RC@VVenC 移植，报告必须注明版本差异，不能宣称与论文编码器完全等价。

## 路线比较

1. **推荐：完整模块化移植。** 条带分配、依赖因子、ScanDMM 关键 CTU 均保留，分别提供消融开关。ScanDMM 离线生成轨迹，C++ 编码器仅消费轨迹，便于固定随机种子并复核 POC 映射。
2. 仅复现纬度条带分配。依赖较少，但缺少式(16)与注视机制，只能作为消融项。
3. 将 ScanDMM 在线嵌入编码器。路径直接，但增加 Python/PyTorch/GPU 与编码生命周期耦合，首版收益有限。

## 组件与数据流

新增独立 `VisualGazeRc` 模块，在 `VtmRcCompat::Adapter` 的 beginPicture / decideCtu / feedbackCtu / finishPicture 接入。关闭算法时执行原基线路径，原 VTM RC 数值内核保持可独立回放。

1. 原始亮度帧预分析：按式(6)-(8)以像素中心计算纬度权重，正确处理底部/右部不完整 CTU；依据 ACO 产生空间复杂度，依据运动信息和空间特征差产生时间复杂度。采用预分析运动估计以避免使用尚未编码 CTU 的最终 MV；此实现选择需在报告标注。
2. 逐 CTU 行作为条带。式(9)-(12)在条带开始使用当前帧剩余预算、剩余条带特征及纬度信息，随后按条带剩余预算和 CTU 权重分配。不能用简单乘纬度权重替代条带预算反馈。式(10)不擅自改成特征与纬度乘积的整体归一化。
3. 用条带 CTU 目标预算驱动原 RC λ/QP 估计及模型反馈；同一条带扣减真实完成 CTU 的估计编码比特，帧结束以实际 NAL 比特闭环。
4. 按式(17)-(19)比较当前 CTU 特征与帧均值生成复杂度类别；按式(28)-(30)从已重建 CTU 失真和相关性得到依赖因子。I 帧采用上/左邻居，P 帧采用 L0 前两个参考，B 帧采用 L0/L1 第一参考。不存在的依赖项为零，不读取未来重建数据。参考按实际 POC 查找，缓存只保留编码器仍使用的参考帧。
5. 式(16)：关键 CTU 使用 `phi * lambda_base`，非关键且低复杂度使用 `lambda_base / phi`，其余不变。映射后 QP 相对优化前限制为 [-2,2]；记录未裁剪 λ、最终 λ/QP 及裁剪原因，防止编码与反馈使用不同决策。

## ScanDMM 接口

来源：https://github.com/xiangjieSui/ScanDMM 。官方输出数组为 `(observers, length, 2)`，最后一维是归一化 `(y,x)`。论文要求 49 个观察者，低延迟 GOP16、RA GOP32。

离线生成每段 49 条轨迹，保存模型哈希、原图哈希、随机种子、依赖版本和显式 `source_poc / target_poc` 映射，再转换为 CTU 标记。按显示 POC 对齐，不能按 RA 编码顺序索引；经度环绕、纬度边界及重复注视点规则固定并测试。缺轨迹、长度不足、非有限坐标和不匹配尺寸均报错。人工/随机轨迹只可用于接口测试，不能作为完整方案实验输入。

论文把每个 GOP 的首帧称为 intra-frame，与标准低延迟仅初始 I 帧/RA 周期 I 帧的结构存在语义差异。首版以每个显示顺序 GOP 起始原始帧作为 ScanDMM 图像输入，同时明确这是待作者资源核实的移植约定，不能擅自增加 I 帧。

## 验证与验收

逐层执行：基线编译与 CTest/数值回放；公式与边界检查；小尺寸真实闭环编码/解码；ERP 序列四目标码率实验。检查预算扣减、有限正 λ、QP 差限制、参考 POC 和轨迹映射、重复运行确定性。关闭新方案时与独立基线比特流一致。

同一平台同一配置比较：固定 QP、原 VTMRC、仅条带、条带+依赖、完整方案。目标码率从 QP22/27/32/37 固定 QP 编码取得。LDP/LDB GOP16、RA GOP32；先短序列检查，之后执行与论文对应的实验长度（论文明确 LDB/RA 为前100帧；LDP 长度需核对表格或原始材料）。

输出 WS-PSNR、S-PSNR、BD-rate、绝对码率误差、帧比特与式(32)虚拟缓冲曲线及编码时间。缓冲曲线需固定并公开 N0；它不是 HRD 合规证明。保存命令、输入/源码/模型/轨迹哈希和原始 CSV。性能无增益仍如实交付，不以构造的实验声称重现论文收益。
